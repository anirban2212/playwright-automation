# playwright-automation
Project Overview
This project is a Playwright automation framework built using the Page Object Model (POM) design pattern, TypeScript, and Cucumber for BDD-style testing.

Tech Stack:

Playwright
TypeScript
Cucumber
Page Object Model (POM)
Folder Structure:

All actions, hooks, assertions, and supporting code are located under the src directory.
All test-related files, including feature files and step definitions, are located under the tests directory.
